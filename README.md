# ELPA21 Reading Studio

Mississippi ELPT / ELPA21-style **reading practice platform** for English learners, K–12.
Built by EL Publishing · Richard A. Daniel, M.Ed., ENL/EL Specialist, Laurel High School.

**Live site:** https://radan55.github.io/RichardDaniel/elpa21-reading-studio/

## What it does
- Six grade bands (K, 1, 2–3, 4–5, 6–8, 9–12) · 122 original items · 22 Mississippi-rooted texts
- Eight ELPA21-style item types: multiple choice, picture choice, multiple select, hot text, ordering, matching table, fill-in-the-blank, claim/evidence classification
- Four session modes: Quick Check, Guided Practice, Full Mock Test (DRC INSIGHT-style), Skill Drill
- Universal tools and accommodations: read-aloud, line reader, masking, highlighter, answer eliminator, notepad, zoom, color contrast, dyslexia-friendly font
- Bilingual EN/ES directions and tap-to-see glossary (auto-off in mock mode)
- Estimated Level 1–5, score reports by ELP standard / skill / item type, XP, streaks, badges, certificates
- Teacher dashboard: class codes, report-code import, roster, mastery heatmap, item analysis, CSV export, JSON backup

## Deploy
Single self-contained `index.html`. Settings → Pages → Deploy from branch (`main`, `/root`).
Student progress is stored in each browser (localStorage); nothing is sent to a server.

## Notes
Original practice content written in the style of the ELPA21 reading domain. Not affiliated with ELPA21, CRESST, DRC, or the Mississippi Department of Education. Level estimates are for practice only.
